Privacy Policy for Save Image as Type v2

Overview

"Save Image as Type v2" is a Chrome extension that allows users to convert and download images from web pages in various formats (PNG, JPG, WEBP, GIF, BMP). Your privacy is important. This policy explains what data the extension accesses and how it is handled.

Data Collection

This extension does not collect, store, transmit, or share personal data. The extension does not use analytics, tracking, cookies, or remote third-party services. There are no user accounts, no sign-ins, and no external servers involved. Everything runs locally on your machine.

What the Extension Accesses

The extension accesses the following data to perform its core functionality:

  • Images on the current web page: To decode, convert, and download them when requested via the context menu.
  • Image URLs: To fetch image data for format conversion. URLs are processed locally and are never transmitted outside your browser.

Permissions Used

  • Host permissions (<all_urls>): Required to bypass strict CORS restrictions. This allows the extension to read pixel data from images hosted on cross-origin servers.
  • contextMenus: To add the format options to your right-click menu.
  • downloads: To save converted images to your device and route them to your preferred sub-folders.
  • storage: To save your preferences configured on the Options page.
  • offscreen: To process memory-intensive tasks (like converting animated WebP/APNG files into GIFs) in the background without freezing your active tab.

How Data is Processed

All image processing (format conversion, animated frame extraction, GIF encoding) happens within your browser using native APIs and bundled local scripts (like gif.js). No image data or browsing history is ever sent to any external server. Converted files are saved directly to your local system.

Data Storage

The extension only uses chrome.storage.local to remember your extension settings (such as file naming rules and toggle states from the Options page). This data never leaves your device.

Children's Privacy

This extension does not knowingly collect information from children under 13. It does not collect information from anyone.

Changes to This Policy
