Save Image as Type v2
Save Image as Type v2 The original extension (with over 1 million downloads!) was recently removed from the Web Store due to spyware. This fork is built from a clean, original Save Image as Type base, with no 'shady' stuff. It also adds support for GIF, along with the options page!
